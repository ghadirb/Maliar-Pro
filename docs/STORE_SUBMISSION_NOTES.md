# متن‌های آماده برای انتشار در بازار و مایکت

این فایل برای کپی مستقیم در کنسول توسعه‌دهندگان بازار/مایکت است. نسخه‌ی مرتبط: `versionCode 4`
/ `versionName 1.3` (برنچ `test-39-secure-ai-proxy`).

---

## ۱. توضیحات نسخه جدید (برای کاربران - فیلد "تغییرات این نسخه")

### نسخه‌ی کامل

```
🆕 نسخه جدید مالیار پرو - مجموعه امکانات مالی حرفه‌ای

📅 یادآوری اقساط و چک‌های نزدیک
همین بالای صفحه حسابداری، تمام چک‌ها و اقساطی که به سررسید نزدیک شده‌اند را یک‌جا ببینید.

📊 گزارش‌های مالی حرفه‌ای
- مشاهده وضعیت مالی روزانه، هفتگی، ماهانه و سالانه
- بیشترین هزینه‌ها و درآمدهای شما
- دسته‌ای که بیشترین خرج در آن انجام شده
- نمودار روند درآمد و هزینه

🗓 تقویم مالی شمسی
تمام اقساط، بدهی‌ها، چک‌ها، سررسیدها و یادآوری‌های شما روی یک تقویم شمسی کامل و قابل مرور
بین ماه‌ها (با دکمه یا با سوایپ)

🤝 مدیریت بدهکار و طلبکار
برای هر شخص: مبلغ بدهی، پرداخت‌های انجام‌شده، مانده حساب، تاریخ سررسید و تاریخچه کامل
تراکنش‌ها

💡 پیشنهادهای هوشمند مالی
مالیار حالا با تحلیل هزینه‌های شما، نکات مفید به‌صورت اعلان به شما می‌دهد؛ مثلاً تغییر
هزینه‌ها نسبت به ماه قبل یا پیش‌بینی وضعیت مالی پایان ماه

💾 پشتیبان‌گیری حرفه‌ای‌تر
وضعیت آخرین پشتیبان‌گیری همیشه قابل مشاهده است؛ بازیابی سریع فقط با یک ضربه

🔒 بهبودهای امنیتی
تقویت زیرساخت ارتباط دستیار هوش مصنوعی برای محافظت بهتر از اطلاعات شما

بهبودها و رفع اشکالات جزئی نیز در این نسخه انجام شده است.
```

### نسخه کوتاه (اگر محدودیت کاراکتر دارید)

```
🆕 این نسخه چه چیزی اضافه دارد:
✅ نمایش اقساط و چک‌های نزدیک به سررسید در بالای صفحه حسابداری
✅ گزارش‌های مالی حرفه‌ای (روزانه/هفتگی/ماهانه/سالانه) با نمودار روند و پرهزینه‌ترین موارد
✅ تقویم مالی شمسی کامل با نمایش اقساط، بدهی‌ها و چک‌ها (قابل جابه‌جایی با سوایپ)
✅ بخش جدید مدیریت بدهکار و طلبکار با تاریخچه پرداخت‌ها
✅ پیشنهادهای هوشمند مالی به‌صورت اعلان روزانه
✅ پشتیبان‌گیری حرفه‌ای‌تر با وضعیت همیشه‌قابل‌مشاهده و بازیابی سریع
✅ تقویت امنیت ارتباط دستیار هوش مصنوعی
✅ رفع اشکالات و بهبود عملکرد
```

### نسخه خیلی کوتاه (فیلدهای با محدودیت شدید)

```
افزودن گزارش‌های مالی حرفه‌ای، تقویم مالی شمسی، مدیریت بدهکار/طلبکار، یادآوری اقساط و
چک‌های نزدیک، پیشنهادهای هوشمند مالی، پشتیبان‌گیری حرفه‌ای‌تر و تقویت امنیت + رفع باگ‌ها.
```

## ۲. توضیح برای تیم بررسی (فیلد "توضیحات برای بررسی‌کننده" / "یادداشت داخلی")

این متن مخصوص کارشناس بررسی‌کننده‌ی بازار/مایکت است، نه کاربر نهایی - هدفش شفاف کردن
دلیل مجوزها و رفتارهای اپ برای رد نشدن یا سوال نشدن غیرلازم است.

```
مالیار پرو یک برنامه‌ی مدیریت مالی شخصی (حسابداری، یادآوری قسط/چک، بدهکار و طلبکار،
گزارش مالی، تقویم مالی) با یک دستیار هوش مصنوعی اختیاری است. توضیح مجوزها و رفتارهای
اپ که ممکن است در بررسی سوال‌برانگیز باشند:

۱) اعلان‌ها (POST_NOTIFICATIONS) و زنگ دقیق (SCHEDULE_EXACT_ALARM/USE_EXACT_ALARM):
برای یادآوری قسط/چک/رویداد در زمان دقیق تعیین‌شده توسط خود کاربر - کارکرد اصلی برنامه.

۲) راه‌اندازی بعد از ری‌استارت گوشی (RECEIVE_BOOT_COMPLETED):
بدون این مجوز، تمام زنگ‌های یادآوری بعد از خاموش/روشن شدن گوشی توسط سیستم‌عامل پاک
می‌شوند و کاربر دیگر یادآوری دریافت نمی‌کند؛ این receiver فقط زنگ‌های موجود را دوباره
ثبت می‌کند.

۳) سرویس پیش‌زمینه (FOREGROUND_SERVICE / specialUse) و معافیت از بهینه‌سازی باتری
(REQUEST_IGNORE_BATTERY_OPTIMIZATIONS):
برخی گوشی‌ها (شیائومی/هواوی/سامسونگ و...) به‌صورت پیش‌فرض اپ‌های پس‌زمینه را می‌بندند و
مانع رسیدن یادآوری‌ها می‌شوند؛ این‌ها فقط برای قابل‌اعتماد بودن یادآوری‌ها هستند، نه
جمع‌آوری داده یا ردیابی کاربر. کاربر می‌تواند این‌ها را از تنظیمات برنامه غیرفعال کند.

۴) نمایش تمام‌صفحه هنگام یادآوری (USE_FULL_SCREEN_INTENT):
مشابه زنگ ساعت گوشی - برای یادآوری‌های مهم (مثل سررسید چک) که نباید در نوتیفیکیشن‌بار
گم شوند، مثل اپ‌های Alarm Clock استاندارد.

۵) دستیار هوش مصنوعی و ارتباط شبکه:
درخواست‌های دستیار هوش مصنوعی (برای کاربرانی که کلید شخصی وارد نکرده‌اند) از طریق یک
پراکسی سمت سرور (Google Apps Script که توسط توسعه‌دهنده میزبانی می‌شود) انجام می‌شود.
هیچ کلید API یا رمزی داخل اپ ذخیره نمی‌شود. اطلاعات مالی کاربر فقط در پایگاه‌داده‌ی
محلی روی گوشی خودش ذخیره می‌شود و به هیچ سروری ارسال نمی‌شود، مگر متن سوالی که خودِ
کاربر از دستیار می‌پرسد (که فقط برای تولید پاسخ استفاده می‌شود).

۶) خرید درون‌برنامه‌ای:
از طریق SDK رسمی بازار/مایکت (myket-billing-client) برای اشتراک پرمیوم انجام می‌شود.

هیچ داده‌ای بدون اطلاع کاربر جمع‌آوری، ردیابی یا با شخص ثالث تبلیغاتی به اشتراک گذاشته
نمی‌شود. با تشکر از بررسی شما.
```
